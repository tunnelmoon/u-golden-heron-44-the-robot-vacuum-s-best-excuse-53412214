# The Robot Vacuum's Best Excuse

Entry for the make.fun bounty [The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

One line, 74 characters, in the vacuum's own deadpan voice:

> My cliff sensor mistook the dust bunny for a pet, and I don't vacuum pets.

`main.ts` validates the line (1-140 characters, single line, not only whitespace) and writes it to `/output/entry.txt`.
